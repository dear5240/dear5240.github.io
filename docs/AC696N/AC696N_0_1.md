## 一、AC696N通用核心功能

- 搭载 32 位带硬件浮点运算单元（FPU）的 DSP 处理器，最高可编程主频 160MHz，内置 136KB RAM
- 支持 SBC、AAC 蓝牙音频解码与 mSBC 蓝牙通话编解码，全格式兼容 MP2、MP3、WMA、APE、FLAC、AAC、WAV 等主流音频解码
- 内置专业音频处理能力：支持语音丢包补偿（PLC）、声学回声消除 / 抑制（AEC/AES），配备多频段 DRC 限幅器，支持 10 段EQ 均衡器
- 集成高规格音频 Codec：1 通道 16 位 ADC（信噪比 SNR≥90dB），支持 8KHz~48KHz 全档位采样率
- 符合蓝牙 V6.0 BR+EDR+BLE 双模规范，最大 + 6dBm 发射功率、最低 - 90dBm 接收灵敏度，内置快速 AGC 电路，兼容全主流蓝牙音频协议
- 配备丰富外设：全速 USB 2.0 OTG 控制器、6 个支持捕获 / PWM 的 32 位多功能定时器、3 路全双工 UART（2 路支持 DMA）、主从模式硬件 IIC 接口、10 位 ADC，全 GPIO 支持外部唤醒与中断
- 集成电源管理单元（PMU），内置多路线性稳压器（LDO）；软关断模式待机功耗低至 3uA，I/O 口供电范围 2.2V~3.6V
- 存储温度范围覆盖 - 65℃~+150℃，适配多场景应用需求
